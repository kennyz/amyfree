# Amyfree 1.5.0

- 新增统一 **升级中心**：Amyfree、GeoIP、GeoSite、MMDB 分别提供升级按钮。
- 显示真实下载百分比、已下载大小及校验状态；规则库可单独升级。
- 每 24 小时自动检查，菜单栏、升级入口和对应项目以红点提示。检查时间与提醒跨重启保留，完成对应升级后消除。
- 保留签名、文件校验和失败回退；应用升级后自动重开，规则库更新后重新启用代理生效。

`1.4.x` 用户可通过旧菜单「工具 → 检查更新」升级，之后从盾牌菜单打开「升级中心」。也支持 README 中的 curl 安装命令。

适用于 **macOS 13+、Apple Silicon**，安装包自带内核、规则库和 Python。已使用 **Apple Developer ID 正式签名，尚未 Apple 公证**；首次打开如被阻止，请在「隐私与安全性」中允许。
