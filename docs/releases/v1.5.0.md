# Amyfree 1.5.0

- New unified **Upgrade Center**: Amyfree, GeoIP, GeoSite and MMDB each have their own upgrade button.
- Shows the real download percentage, downloaded size and verification status; rule data can be upgraded individually.
- Checks automatically every 24 hours, with red dots on the menu bar icon, the Upgrade Center entry and the matching items. Check times and reminders persist across restarts and clear once the matching upgrade completes.
- Signatures, file verification and rollback on failure are kept; the app reopens after upgrading, and rule data updates take effect the next time the proxy is turned on.

`1.4.x` users can upgrade through the old menu Tools → Check for Updates, then open the Upgrade Center from the shield menu. The curl install command in the README also works.

For **macOS 13+, Apple Silicon**; the package bundles the core, rule data and Python. Signed with an **Apple Developer ID, not yet notarized by Apple**; if the first launch is blocked, allow it in Privacy & Security.
