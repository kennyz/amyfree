# Amyfree 1.6.0

- 中英双语界面：在「设置 → 语言 / Language」切换，菜单、窗口、提示和运行脚本的输出同步切换；默认跟随系统语言。
- 菜单选择节点现在真正生效：固定 PROXY 组到所选节点；新增「自动选择（最快）」恢复自动测速选择。当前节点与勾选标记显示实际承载流量的节点。
- 分流设置分为「基础分流」与「自定义规则」两页，并新增「地址测试」：查看网址命中的规则、出口节点和访问结果。
- 节点自动检测间隔改为每 3 分钟。
- 修复 TUN 模式下菜单显示「关闭」、无法切换节点，以及保存链式代理、分流和订阅失败的问题（内核以 root 运行时的文件权限）。
- GitHub 首页改为英文，中文说明见 README.zh-CN.md。

适用于 macOS 13+、Apple Silicon。订阅、设置和原规则库保持不变。

本次为 Apple Developer ID 正式签名版本，尚未 Apple 公证。DMG/ZIP 内置 mihomo 内核、规则库和 Python，附 SHA-256 校验清单。
