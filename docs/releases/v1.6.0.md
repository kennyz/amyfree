# Amyfree 1.6.0

- Bilingual Chinese/English interface: switch in Settings → 语言 / Language, and the menu, windows, messages and runtime script output all switch together; defaults to the system language.
- Choosing a node from the menu now really takes effect: the PROXY group is pinned to the chosen node, and the new "Auto (fastest)" item restores automatic latency-based selection. The current node and checkmark show the node actually carrying traffic.
- Routing settings are split into "Basic Routing" and "Custom Rules" pages, with a new "Address Test" that shows which rule a URL matches, the exit node and the result.
- The automatic node check interval is now every 3 minutes.
- Fixed the menu showing "Off" in TUN mode, being unable to switch nodes, and failures saving chain proxy, routing and subscriptions (file permissions when the core runs as root).
- The GitHub home page is now in English; the Chinese guide is README.zh-CN.md.

For macOS 13+, Apple Silicon. Subscriptions, settings and existing rule data are unchanged.

This release is signed with an Apple Developer ID, not yet notarized by Apple. The DMG and ZIP bundle the mihomo core, rule data and Python, with a SHA-256 checksum list.
