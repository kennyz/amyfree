# Amyfree 1.5.2

- Download progress is now a fixed fill bar that grows with the real percentage; the side-to-side animated bar is gone for good.
- Rule data updates take the total size from pinned-version file metadata; when the size is unknown they show the MB downloaded instead of fake progress.
- Verification and saving after the download keep the completed progress.
- Tools → Upgrade Center, independent upgrades, daily checks and red-dot reminders are kept.

The app and package are signed with a Developer ID, not yet notarized by Apple. For macOS 13+, Apple Silicon. Subscriptions, settings and existing rule data are unchanged.
