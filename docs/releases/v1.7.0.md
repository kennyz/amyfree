# Amyfree 1.7.0

- 将菜单栏主程序和运行时辅助工具迁移到 Rust，安装包不再依赖 Python；部分原生窗口继续通过 Swift 桥接。
- 新增自定义节点管理，支持链接和二维码导入、节点编辑及删除。
- 更新猫咪菜单栏图标，并支持开关实时网速显示。
- 保留统一升级中心、下载进度显示及 GeoIP、GeoSite、MMDB 在线更新。

适用于 Apple Silicon Mac，macOS 13 及以上。安装包已内置 mihomo 内核和规则库，可下载 DMG 或 ZIP，也可通过 README 中的 curl 命令安装。

应用及 DMG 使用 Developer ID 签名，尚未经过 Apple 公证。下载后可用 SHA256SUMS.txt 校验文件。

仅用于合法合规的网络访问及科研学习，禁止用于任何政治等非法目的。使用者应遵守所在地法律法规。
