# Amyfree 1.3.4

A lightweight, simple macOS menu bar proxy tool: import a subscription, choose a node, connect with one click.

- Bundles the mihomo core, rule data and Python, so there are no developer tools to install and no terminal scripts to run.
- Supports common subscriptions, automatic latency checks, download speed tests, routing rules and certificate expiry warnings.
- On first launch it guides you through entering a subscription; upgrades keep your existing subscription and settings.

**System requirements: macOS 13 or later, Apple Silicon (M-series chips).**

Download the **DMG** below, open it and drag Amyfree into Applications, then launch it and enter your own lawful subscription. The ZIP contains the same app; `SHA256SUMS.txt` is for verifying downloads, and `mihomo-v1.19.32-source.tar.gz` is the matching core source.

**Signing status: signed with an Apple Developer ID Application certificate, and the signatures of the bundled app and core have been verified; not yet notarized by Apple.** If macOS blocks the first launch, choose "Open Anyway" in System Settings → Privacy & Security.
