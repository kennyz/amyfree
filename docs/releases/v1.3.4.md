# Amyfree 1.3.4

轻量、简洁的 macOS 菜单栏代理工具：导入订阅，选择节点，一键连接。

- 内置 mihomo 内核、规则库和 Python，无需安装开发工具或运行终端脚本。
- 支持常见订阅、自动延迟检测、下载测速、分流和证书到期提醒。
- 首次打开引导填写订阅，升级保留已有订阅和设置。

**适用系统：macOS 13 及以上，Apple Silicon（M 系列芯片）。**

下载下方 **DMG**，打开后将 Amyfree 拖入 Applications，再启动并填写自己的合法订阅。ZIP 为同一应用的压缩包；`SHA256SUMS.txt` 用于下载校验，`mihomo-v1.19.32-source.tar.gz` 为内核对应源码。

**签名状态：已使用 Apple Developer ID Application 正式签名，已验证安装包内应用及内核的签名完整性；尚未完成 Apple 公证。** 若首次打开被 macOS 阻止，请在「系统设置 → 隐私与安全性」中选择「仍要打开」。
