# Amyfree 1.4.1

- New **Tools → Update Rule Data…** updates GeoIP, GeoSite and MMDB online.
- SHA-256 is verified automatically and the core checks the file format; on failure the old data is kept, and a failed replacement is rolled back automatically.
- Updates keep current connections; the new rule data loads the next time the proxy is turned on. Subscription and routing settings are unchanged.
- Fixed source installs missing the core and rule data.

`1.4.0` users can upgrade from Tools → Check for Updates, or use the curl install command in the README.

For **macOS 13+, Apple Silicon**. The DMG and ZIP both bundle the core, rule data and Python.

Signed with an **Apple Developer ID, not yet notarized by Apple**. If the first launch is blocked, allow it in System Settings → Privacy & Security.
