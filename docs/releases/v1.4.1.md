# Amyfree 1.4.1

- 新增 **工具 → 更新规则库…**，在线更新 GeoIP、GeoSite 和 MMDB。
- 自动校验 SHA-256，并用内核检查文件格式；失败保留旧库，替换失败自动回退。
- 更新保留当前连接，重新启用代理后加载新规则库；订阅和分流设置保持不变。
- 修复源码安装遗漏内核和规则库的问题。

`1.4.0` 用户可在「工具 → 检查更新」升级，也可使用 README 中的 curl 安装命令。

适用于 **macOS 13+、Apple Silicon**。DMG/ZIP 均自带内核、规则库和 Python。
