# Amyfree 1.4.0

- **在线升级**：菜单栏 → 工具 → 检查更新，确认后下载安装并重新打开；启动后及每天自动检查新版。
- **curl 一键安装**：自动下载最新稳定版，校验 SHA-256 和 Developer ID 签名，保留已有订阅和设置。
- 安装失败保留原应用，替换失败自动恢复。内置运行依赖，无需安装开发工具。

```bash
curl -fsSL https://raw.githubusercontent.com/kennyz/amyfree/main/scripts/install.sh | bash
```

适用于 **macOS 13+、Apple Silicon**。也可下载下方 DMG，将 Amyfree 拖入 Applications。`1.3.4` 及更早版本需先通过 curl 或 DMG 更新一次，之后即可使用应用内更新。

已使用 **Apple Developer ID 正式签名，尚未 Apple 公证**。首次打开如被阻止，请在「系统设置 → 隐私与安全性」中允许。

**仅用于合法合规的科学上网、学习、科研和工作。禁止用于政治活动及任何违法违规目的。使用者应遵守所在地法律法规，并对自身使用行为负责。** 不提供订阅或节点服务。

DMG/ZIP 为同一应用；`SHA256SUMS.txt` 用于校验，`mihomo-v1.19.32-source.tar.gz` 为内核对应源码。
