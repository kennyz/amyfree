# Amyfree 1.4.0

- **Online upgrades**: menu bar → Tools → Check for Updates. After you confirm, it downloads, installs and reopens; new versions are also checked at launch and daily.
- **One-line curl install**: downloads the latest stable release, verifies the SHA-256 and Developer ID signature, and keeps your existing subscription and settings.
- A failed install keeps the original app, and a failed replacement is rolled back automatically. Runtime dependencies are bundled; no developer tools needed.

```bash
curl -fsSL https://raw.githubusercontent.com/kennyz/amyfree/main/scripts/install.sh | bash
```

For **macOS 13+, Apple Silicon**. You can also download the DMG below and drag Amyfree into Applications. `1.3.4` and earlier need one update via curl or the DMG first; after that, in-app updates work.

Signed with an **Apple Developer ID, not yet notarized by Apple**. If the first launch is blocked, allow it in System Settings → Privacy & Security.
